# Données de tracé

`kana-strokes.json` contient la forme et l'ordre des traits des hiragana et katakana utilisés par Hanko
(pour chaque kana : `d` = chemins SVG des traits dans l'ordre, `p` = points échantillonnés pour la reconnaissance).
